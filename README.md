# Portafolio Linux + GitHub

## Descripción
Este portafolio contiene las actividades desarrolladas durante la Semana 16, utilizando Ubuntu Linux, Git y GitHub.

## Objetivo
Demostrar el manejo de comandos Linux, la creación de repositorios Git, el control de versiones, la administración de ramas y el trabajo colaborativo mediante GitHub.

## Actividades realizadas

- Actividad 2: Creación de un repositorio local.
- Actividad 3: Vinculación del repositorio local con GitHub.
- Actividad 4: Creación y fusión de ramas.
- Actividad 5: Trabajo colaborativo con GitHub.
- Actividad 6: Desarrollo y publicación del portafolio.

## Estructura del proyecto

- `README.md`: Descripción del portafolio.
- `estudiante.txt`: Información del estudiante.
- `actividad16.txt`: Práctica de la Semana 16.
- `comandos_linux.txt`: Registro de diez comandos Linux y Git.
- `evidencias/`: Capturas de las actividades realizadas.

## Herramientas utilizadas

- Ubuntu Linux
- Oracle VirtualBox
- Git
- GitHub

## Conclusión

El desarrollo de este portafolio permitió aplicar comandos de Linux, gestionar versiones mediante Git, trabajar con ramas y sincronizar archivos con repositorios remotos en GitHub.
